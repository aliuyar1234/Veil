# Implementation Plan: PDF Parser

**Branch**: `005-pdf-parser` | **Date**: 2025-12-15 | **Spec**: spec.md
**Input**: Feature specification from `/specs/005-pdf-parser/spec.md`

## Summary

Implement PDF text extraction for the veil-parsers crate, enabling PII detection in PDF documents.
Uses pure-Rust `pdf-extract` crate for text extraction with position metadata.

## Technical Context

**Language/Version**: Rust (stable, 1.75+)
**Primary Dependencies**: pdf-extract, pdf
**Storage**: In-memory processing with streaming for large files
**Testing**: cargo test, TDD per constitution
**Target Platform**: Cross-platform library (Linux, macOS, Windows)
**Project Type**: Library extension to veil-parsers
**Performance Goals**: 100 pages in <10s, <500MB memory for 1000 pages
**Constraints**: No external C dependencies, pure Rust

## Implementation Phases

### Phase 1: Setup & Core Types

1. Add dependencies to veil-parsers Cargo.toml
2. Create pdf module structure
3. Implement PdfError types
4. Implement PdfParseOptions
5. Add Position::Pdf variant

### Phase 2: Basic Text Extraction

1. Implement PdfDocument::from_bytes()
2. Implement PdfPage structure
3. Implement PdfTextBlock extraction
4. Implement reading order sorting
5. Convert to TextSegment output

### Phase 3: Position & Metadata

1. Implement bounding box extraction
2. Add page number tracking
3. Implement byte offset calculation
4. Extract document metadata (title, author)

### Phase 4: Form Field Extraction

1. Implement PdfFormField structure
2. Extract text field values
3. Extract checkbox/radio values
4. Extract dropdown selections
5. Include form fields in text output

### Phase 5: Edge Cases & Detection

1. Implement encrypted PDF detection
2. Implement scanned page detection
3. Handle corrupted PDF gracefully
4. Add warning for no-text documents
5. Test with sample PDFs

### Phase 6: Integration & Polish

1. Add PDF to format detection
2. Integrate with parse_bytes()
3. Documentation and examples
4. Performance validation
5. Memory usage validation

| Risk | Mitigation |
|------|------------|
| Complex PDF layouts | Focus on standard layouts, document limitations |
| Memory for large PDFs | Streaming page processing |
| Encoding issues | Rely on pdf crate, log warnings for failures |
| Scanned PDFs | Clear error message, suggest OCR |
| Performance targets | Benchmark early, optimize if needed |
